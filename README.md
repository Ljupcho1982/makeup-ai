# Šminka Ocenka (MakeupAI)

Android aplikacija koja ocenuva dali e nekoja žena dobro našminkana. Slika se snima so kamera, bira od galerija ili se vcituva od https link. Analizata e na uredot (ML Kit face detection + analiza na boja).

Preuzmi APK: vidi **Releases**. Ocenkata e približna evristika, ne ocenuva ubavina.

Build: `gradlew assembleRelease` (JDK 17, Android SDK 36).
